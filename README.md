# Eligio: The right trial, found faster.

Breast cancer clinical trial pre-screening for New York City research coordinators.
NYU Stern TECH-GB.3332 term project (Taryn Samet, Grace Kirkpatrick). Decision support only; synthetic patients.

Hosted on Render (free web service): build `pip install -r requirements.txt`, start `python app.py`.
Environment variables (set in Render, never in this repo): GEMINI_API_KEY (required),
GEMINI_MODEL (gemini-3.5-flash-lite), APP_PASSWORD (optional login, user "coordinator").
